Human-Centered Design (HCD): Lead the end-to-end design process by conducting user research, developing user personas, crafting journey maps, and building service blueprints to address user pain points effectively.
Prototyping & Wireframing: Design low-fidelity wireframes and high-fidelity interactive prototypes using industry-standard tools (e.g., Figma, Sketch, Adobe XD) to visualize complex workflows and system interactions.
Usability Testing: Plan and facilitate usability testing sessions with federal stakeholders and end-users, gathering qualitative and quantitative feedback to drive continuous iterative improvements.
Frontend Collaboration: Work hand-in-hand with Full Stack Developers to ensure that designs are technically feasible and meticulously translated into responsive, high-performance web applications, primarily utilizing the React.js framework.
Accessibility & Compliance: Ensure all user interfaces strictly adhere to federal Section 508 accessibility compliance standards, W3C Web Content Accessibility Guidelines (WCAG), and agency-specific design systems.
Design Systems & Standardization: Create, maintain, and advocate comprehensive design systems, style guides, and component libraries to ensure visual consistency across all BEAR Task Order deliverables.
Agile Integration: Participate actively in a Scaled Agile Framework (SAFe) environment, contributing to sprint planning, backlog grooming, and delivering design artifacts that align with the Agile Release Train (ART).
Experience: Minimum of 5+ years of professional experience in UI/UX design, with a strong portfolio demonstrating complex enterprise software or web application design.
Design Tools: High proficiency in modern UI/UX design and prototyping tools, specifically Figma, as well as the Adobe Creative Suite.
Technical Understanding: Solid understanding of frontend web technologies (HTML5, CSS3, JavaScript) and how design decisions impact frontend framework
