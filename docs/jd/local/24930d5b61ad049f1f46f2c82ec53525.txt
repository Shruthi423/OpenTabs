The Mobile Game UI/UX Designer will design intuitive and visually engaging interfaces for mobile games, from wireframes and user flows to polished in-game screens and menus. You will collaborate closely with game designers, artists, and developers to create cohesive user experiences, iterate on feedback, and ensure usability across devices and platforms. Daily work includes conducting user research and playtesting, refining interaction patterns, creating UI assets and style guides, and maintaining consistency with the game’s visual and narrative direction. You will also help define and document best practices for mobile UI/UX within the studio, contributing to both current projects and future prototypes.
Qualifications
Strong skills in mobile UI design and UX design for games, including user flows, wireframes, and interaction design.
Proficiency with design and prototyping tools for creating and iterating on UI assets.
Experience applying user-centered design methods, including user research, usability testing, and analyzing player feedback.
Ability to collaborate effectively with multidisciplinary teams, communicate design decisions clearly, and respond constructively to critique.
Understanding of mobile game design principles, free-to-play UX considerations, and platform guidelines.
Strong visual design skills, including typography, color theory, layout, and iconography tailored to game aesthetics.
Portfolio demonstrating shipped or prototype mobile games, interactive experiences, or other relevant UI/UX work.
Experience with basic graphic asset creation and exporting for game engines is a plus.
Interest in experimental, cross-disciplinary projects and playful interactive concepts is highly valued.
