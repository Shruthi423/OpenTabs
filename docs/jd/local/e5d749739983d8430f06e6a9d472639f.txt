Job Description:
The User Experience (UX) Architect will support the Navy Readiness Reporting Enterprise (NRRE) by analyzing software workflows, designing intuitive user interfaces, and developing effective software solutions for Windows-based web applications. This role requires strong experience in user research, UI prototyping, and applying user-centered design principles. The UX Architect will collaborate closely with cross-functional teams to create seamless, high‑quality user experiences. A bachelor’s degree, at least five years of UX-related experience, proficiency with UX tools (Adobe XD highly desired), a strong portfolio, and an active Secret clearance are required.
Analyzing software application workflows to identify usability challenges and opportunities for improvement.
Planning and designing effective software solutions that align with user needs and mission objectives.
Creating intuitive, user centered interface designs for Windows based web applications.

Developing and testing user interface mockups, wireframes, and interactive prototypes.

Ensuring design consistency, usability, and accessibility across all application features.
