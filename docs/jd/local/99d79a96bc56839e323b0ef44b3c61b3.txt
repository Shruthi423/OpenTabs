As a Desktop UI Developer, you will lead the greenfield effort to bring Circuit to the desktop—building a persistent, ambient, native-grade experience for macOS and Windows that lives where our users work.
Your Impact
As a Desktop UI Developer , you will design and build the Circuit Desktop application—a native-grade, cross-platform experience for macOS and Windows that brings AI-driven productivity to the desktop. You bring the full skill set of a modern web UI developer (Angular, Node.js, GCP, Figma-driven UX, REST APIs) and extend it to the desktop, bridging the gap between our web application and the operating system.
You will own the desktop shell end-to-end: application lifecycle, OS-level integrations (system tray, notifications, deep linking, always-on presence), installers, and safe auto-updates. This is a high-visibility, high-ownership role where you will define how tens of thousands of Cisco employees experience Circuit as a first-class desktop citizen.
Design, build, and maintain the Circuit Desktop application for macOS and Windows using Electron (or Tauri) with an Angular/TypeScript UI, ensuring a consistent, performant, native-grade experience across both platforms.
Implement desktop-specific functionality—system tray, native notifications, file system access, deep linking, global shortcuts, and always-on ambient presence—architecting clean IPC communication between the UI (renderer) and main processes with context isolation and sandboxing.
Build responsive AI-driven interfaces (chat, agents, streaming responses) from Figma designs and UX frameworks, integrating with REST APIs and Node.js services, and reusing Circuit's web design system on the desktop surface.
Own cross-platform build pipelines and installers (DMG/PKG for macOS, MSI/NSIS for Windows), including code signing and macOS notarization , hardened runtime, and reliable differential auto-updates .
Integrate native modules where needed (Swift/Objective-C on macOS, C++/C# on Windows), and profile and optimize startup time, memory, and CPU usage; debug native crashes and manage large local state (SQLite/IndexedDB).
Deploy supporting services on Google Cloud Platform , contribute to a multi-platform CI/CD matrix, and collaborate within an Agile team of designers, backend, platform, and quality engineers.
Work with UX and UI designers throughout the product lifecycle, from early feasibility conversations through build and release. Participate in design reviews, give honest input on what is feasible in code, and help scope work so designs can ship without last-minute compromises.
Build interfaces using a shared component library and design tokens, extending existing patterns instead of writing one-off styles. Keep UI consistent, theme-aware, and maintainable as the product grows.
Implement WCAG 2.2 AA patterns for dynamic AI interfaces, including ARIA live regions for streaming responses, semantic structure for conversation UIs, focus management across modals and context switches, full keyboard support, and color contrast in light and dark modes.
Research-informed implementation: Apply findings from usability testing and end-user feedback during development. Know when a design is ready to build versus still in exploration, and raise gaps or edge cases with designers before they become production issues.
Human-AI interaction UI: Build front-end patterns that help users understand AI behavior: streaming and token-by-token rendering, clear loading and error states, recovery flows when responses fail, and UI that supports trust and comprehension in non-deterministic experiences. This is a hybrid position.

Bachelor’s degree with 6+ years, Master’s degree with 4+ years, or PhD with 1+ year of experience in Computer Science or a related technical field.
Proficiency in Angular, TypeScript/JavaScript, and Node.js, with a strong focus on translating Figma designs into scalable, component-based UIs using formal design systems.
